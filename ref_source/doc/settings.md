# 設定選項說明

---

## 全域選項（Options）

由工具列點選「**選項**」按鈕開啟，設定影響全域計算的參數。

| 設定項目 | 說明 | 預設值 |
|----------|------|--------|
| **MDD 顯示數量** | 績效摘要中顯示前幾大 MDD 的詳細資訊 | 5 |
| **資本金額（萬）** | 計算 Sharpe Ratio / Sortino Ratio 時使用的基準資金（萬元） | 100 |
| **無風險利率（%）** | 年化無風險利率，用於計算 Sharpe / Sortino 的超額報酬 | 3 |
| **計算每日 DD** | 勾選後，每日收盤（即使未出場）也計入回撤計算；需重新啟動生效 | 否 |

> **注意**：「計算每日 DD」變更後需關閉並重新開啟程式才會生效。

## 分潤試算設定

在「分潤試算（Commission）」面板中點選「**設定**」按鈕開啟，設定分潤計算的各項參數。

| 設定項目 | 說明 | 預設值 |
|----------|------|--------|
| **回測金額（萬）** | 回測時使用的標準資金規模，用於換算實際資金比例 | 1000 |
| **初始資金（萬）** | 基金起始可用資金 | 1000 |
| **資金槓桿** | 相對於回測金額的槓桿倍數。例：槓桿=3 且回測金額=1000 萬，則實際每1000萬回測獲利對應3倍效果 | 3 |
| **幣安手續費（%）** | 交易所手續費率（雙邊），用於計算退傭基準 | 0.05 |
| **手續費退傭（%）** | 從交手續費中退傭給操盤方的比例 | 30 |
| **季分潤（%）** | 每季若有累積獲利，從獲利中分潤給操盤方的比例 | 30 |
| **績效門檻 1～4（%）** | 年度績效超過此門檻時，適用對應獎金比例；設 0 則無效 | 100/150/200/0 |
| **獎金比例 1～4（%）** | 對應績效門檻的年度績效獎金比例 | 10/20/30/0 |

### 資金與分潤說明

- 實際套用到策略損益的比例係數為：`初始資金 × 資金槓桿 / 回測金額`
- 每季若累積獲利為正，則先按「季分潤%」計算分潤金額，之後清零重新累積。
- 手續費退傭：`總成交金額 × 幣安手續費% × 手續費退傭%`
- 年度績效獎金：根據全年「客戶淨獲利」對應到不同的績效門檻，取最高適用的獎金比例計算。
