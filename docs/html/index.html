VisualPortfolio.Net 使用手冊

VisualPortfolio.Net 是策略組合報表（Visual Portfolio）的網路版，提供免安裝、可分享連結、可與桌面版互通的使用方式。

1. 系統特色

  1. 網頁即開即用：https://visualportfolio.sibuzu.com/
  2. 專案可直接分享：例如 /projects/VP-ZDEMOZ
  3. Desktop VisualPortfolio 可直接下載/上傳網路版專案資料。
  4. 專案資料超過 72 小時未被存取會自動清理（admin 專案不清理）。

2. 帳號與權限

2.1 帳號類型

  • 一般使用者：可建立、編輯、刪除自己的專案。
  • guest：可由 project 連結進入瀏覽，但不可建立/上傳/複製專案。
  • admin：獨立 /admin 登入流程，用於維運管理。

2.2 保留名稱

admin、guest 不能註冊為一般帳號。

2.3 權限矩陣

3. 快速上手流程

  1. 打開首頁 visualportfolio.sibuzu.com。
  2. 第一次會進入 Login / Sign up。
  1. 建立帳號後登入，進入主頁。
  1. 建立專案或開啟既有專案。

4. 專案頁操作說明

  • owner 顯示 （可編輯），非 owner 顯示 （可檢視）。
  • 可檢視模式不可新增/刪除策略，但可調整啟動、顏色、口數、權重、分潤設定做本地重算。
  • 可檢視模式的調整不會寫入 server，Reload 後回復原值。
  • 可透過「複製專案」建立自己的可編輯副本（guest 不可複製）。

6. Desktop VisualPortfolio 上傳/下載

請使用 VisualPortfolio.exe v26.03.17.23964 以上版本。

6.1 上傳

  • 上傳需要登入。
  • project 已存在時必須同 owner 才能覆蓋。
  • guest 不可上傳。

6.2 下載

  • 下載不需要登入。
  • 可直接輸入 project-id 或 project URL。

7. 系統清理規則

  1. 服務啟動時先檢查一次。
  2. 之後每 1 小時檢查一次。
  3. 專案超過 72 小時未 access 會刪除。
  4. user_id=admin 的專案不會被清理。

8. 常見問題

Q1. 為什麼可檢視模式還能改口數/權重？

那是本地試算，僅影響當下畫面，不會存回 server。

Q2. 為什麼 Reload 後值又變回來？

因為可檢視模式不會寫入 server，Reload 會回復原始設定。

Q3. Help icon 行為？

點擊會開啟 /docs，且重用同一個 docs 分頁。
