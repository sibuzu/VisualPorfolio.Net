1. 寫一個「分散指標」，它與FormWinLoss, FormCommission 同一層位階。
2. Class FormDiversity
3. 主策略是由多個子策略，依其權重分配，組合而成。
4. 裡面有9個指標：
   1. 總策略數 
   2. 總交易次數 (N) (主策略決定)
   3. 平均每次交易金額 (主策略決定)
   4. 有效交易次數 ($N_{eff}$) (主策略決定)
      - $N_{eff} = 1 / HHI_{time}$
        - $HHI_{time} = \sum_{i=1}^{n} \left( \frac{\text{Amount}_i}{\text{Total Amount}} \right)^2$
        - $n$：總交易次數。
        - $\text{Amount}_i$：第 $i$ 次交易的金額。
        - $\text{Total Amount} = \sum_{i=1}^{n} \text{Amount}_i$。
   5. 進場效率比 (Entry Efficiency Ratio, EER)  (主策略決定)
      - $EER = \frac{N_{eff}}{N}$
        - $N_{eff}$：有效分散筆數。
        - $N$：總交易次數。
      - EER = 100%：完美的均勻進場。
      - EER = 70% ~ 80%：代表你有大有小，但整體還算分散。
      - EER < 60%：警訊。代表你雖然分批進場，但大筆金額太過突出，分散流於形式。
   6. 風險分散率 (Risk Diversification Ratio, RDR) (主策略-子策略)
      - 公式：$RDR = \frac{\sum w_i \sigma_i}{\sigma_p}$ （個別風險總和 / 合併後的風險）
        - $\sigma_i$ = 策略 i 的標準差（波動度）。
        - $\sigma_p$ = 組合策略的標準差（波動度）。
        - $w_i$ = 策略 i 的權重。   
      - 含義：這代表您的組合透過互相抵銷，讓整體的風險（波動）比各別策略加權總和小了 $23.85\%$。
      - $RDR = 1.0$：完全沒分散（像買三份一樣的東西）。
      - $RDR > 1.0$：有分散效果。數值越高，代表分散得越成功。數值越高（例如 $>1.5$）代表分散效果越驚人。
      - $RDR$ 的大小取決於兩個因素：策略數量 ($N$) 與 策略間的相關性 ($\rho$)。如果策略之間「完全不相關」 ($\rho = 0$)：在這種理想情況下（假設每個策略權重與波動度一致），公式會簡化為 $RDR = \sqrt{N}$
        - 如果你有 2 個 不相關策略：$RDR = \sqrt{2} \approx \mathbf{1.41}$
        - 如果你有 3 個 不相關策略：$RDR = \sqrt{3} \approx \mathbf{1.73}$
        - 如果你有 4 個 不相關策略：$DR = \sqrt{4} = \mathbf{2.00}$
        - 如果你有 10 個 不相關策略：$DR = \sqrt{10} \approx \mathbf{3.16}$
        - 結論：要達到 $DR=2$，你至少需要 4 個完全不相關的策略，且權重分配完美。
   7. 分散相關指數 (Diversity Correlation Index, DCI) (主策略-子策略)
      - $DCI = \frac{\sum_{i} \sum_{j \neq i} w_i \cdot w_j \cdot \rho_{ij}}{\sum_{i} \sum_{j \neq i} w_i \cdot w_j}$
        - $\rho_{ij}$ = 策略 i 和 策略 j 的相關係數。
        - $w_i$ = 策略 i 的權重。
      - DCI = 1：所有策略都同步(完全相關)（例如都是做多台指）。
      - DCI = 0：策略間完全不相關（理想狀態）。
      - DCI < 0：策略間呈現負相關（完美對沖，非常罕見）。 
   8. 獨立策略數 (Independent Strategy Number, ISN) (主策略-子策略)
      - ISN 公式： $N_{ISN} = \frac{(\sum w_{i})^2}{\sum_{i} \sum_{j} w_{i} w_{j} \rho_{ij}}$
        - $\rho_{ij}$ = 策略 i 和 策略 j 的相關係數。
        - $w_{i}$ = 策略 i 的權重。
      - 如果你有 10 個「完全獨立」的策略（相關係數為 0）： $N_{ISN} = \frac{1}{10 \times (0.1)^2} = \mathbf{10}$。這代表你的組合效果等同於買了 10 份完全不相關的資產。
      - 如果你有 10 個「高度相關」的策略（例如都是做多台指）： $N_{ISN}$ 會遠小於 10，可能只有 2 或 3。這代表你的「分散」只是形式上的，實際上風險非常集中。
   9. 分散策略數 (Distributed Strategy Number, DSN) (主策略-子策略)
      - **公式 (正規化)**： $DSN = \frac{n \cdot \sum_{i=1}^{n} (w_{i,t})^2}{\left( \sum_{i=1}^{n} w_{i,t} \right)^2}$
        - $n$：策略數量。
        - $w_{i,t}$：策略 $i$ 在時間 $t$ 的權重或交易量（若未進場則為 0）。
      - **含義**：等使完全分散的策略數。
        - n：完全不重疊（進場分散極佳，平均分散至 n 個策略）。
        - 1：完全重疊（策略高度同步，與1個策略同時進場一樣）。

5. 表格
     | 指標                     | 範圍       | 說明               |
     | ------------------------ | ---------- | ------------------ |
     | 1. 總策略數              | 任意整數   |                    |
     | 2. 總交易次數 (N)           | 任意整數   |                    |
     | 3. 平均每次交易金額         | 任意正實數 |                    |
     | 4. 有效交易次數 ($N_{eff}$) | 1 ~ N      | 愈大愈分散         |
     | 5. 進場效率比 (EER)         | 0%~100%    | 愈大愈分散         |
     | 6. 風險分散率 (RDR)         | >= 1.0     | 愈大愈分散         |
     | 7. 分散相關指數 (DCI)       | -100%~100% | 愈小愈好，0 無相關 |
     | 8. 獨立策略數 (ISN)         | 1 ~ 策略數 | 愈大愈好。         |
     | 9. 分散策略數 (DSN)         | 1 ~ 策略數 | 愈大愈好。         |

6. 實作:
   1. 從策略組合中，取得所有子策略的交易紀錄。
   2. 計算每個子策略的交易次數、平均每次交易金額、有效交易次數、分散效率比、風險分散率、分散相關指數、有效策略數。
   3. 將結果顯示在 FormDiversity 中。
