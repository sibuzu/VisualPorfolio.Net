1. 策略組合管理
   [+ Buy&Hold] [+新增績效] [^ 上傳專案]
   (兩行顯示)

2. Click [+ Buy&Hold] 
   --------------------
   | Buy&Hold            (?)|
   | 日期 [2020-01-01] |
   | 金額(萬) [100] |
   | 商品 [股票] [期貨]   |
   | 代碼 [0050/TX]     |
   | 槓桿 [        ]     |
   --------------------

3. 若是選  [期貨]，才會出現槓桿的欄位，default value = 5, 股票代碼 default 0050, 期貨代碼 default TX, 所有欄位都不用 spin，只要 textbox 輸入即可。

4. 產生的 績效名稱，為 BH{代碼}_{金額}萬
   若已有同名 BH{代碼}_{金額}萬，直接 overwrite。

5. 用 FinMind 取得資料，從{日期}買入後，一直持有到最近一天賣出算績效，並且有每天浮動績效。

6. Click (?) 顯示：
買入股票或期貨後持有，
股票代碼如 2330, 0050, 會配息再投資，
期貨代碼如 TX, TE, TF, GTF, 會 rollover，並用槓桿，
簡化計算，允非整數部位買入。

7. 買入時，可能會有非整數部位，簡化計算，ALLOW 非整數部位買入。

8. Buy&Hold 設定會記住，下次打開沿用上次設定。
