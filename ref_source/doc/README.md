# Visual Portfolio 使用說明

**Visual Portfolio** 是一款 Windows 桌面應用程式，用於整合多個量化交易策略的回測結果，並提供完整的績效分析與視覺化報表。

## 程式功能概覽

| 功能 | 說明 |
|------|------|
| 多策略整合 | 同時載入多個策略的回測結果，合併計算整體績效 |
| 績效摘要報表 | 顯示總獲利、MDD、Sharpe Ratio、Sortino Ratio 等關鍵指標 |
| 損益曲線圖 | 繪製累積損益走勢圖，支援多策略疊圖與回撤圖 |
| 各期損益長條圖 | 以年/季/月為單位顯示損益長條圖，支援滾動平均 |
| 勝負分析 | 分析日/週/月/年的勝率及贏輸金額統計 |
| 部位最佳化 | 透過 Batch Run 同時測試不同的下單口數組合，找出最佳配置 |
| 分潤試算 | 計算基金管理費、績效獎金與手續費退傭的收入試算 |
| 專案儲存/載入 | 將多策略配置儲存為 `.pfo` 專案檔 |
| 匯出功能 | 可匯出合併交易記錄為 XML 格式 |

## 基本操作

### 開啟專案
工具列點選「**開啟**」，選取 `.pfo` 專案檔案。

### 新增策略回測結果
1. 在「**策略管理**」面板中，點選「**+**（新增）** 」按鈕。
2. 選取策略回測結果檔案（支援 `.xml`、`.srp`、`.xrp` 格式）。
3. 可以一次多選多個檔案，批量加入。

### 儲存專案
工具列點選「**儲存**」，選擇存檔位置，儲存為 `.pfo` 格式。

### 匯出合併交易紀錄
工具列點選「**匯出**」，將所有策略的交易記錄合併後匯出為 `.xml`/`.srp`/`.xrp` 格式，可供其他工具再次分析。

### 還原預設版面
工具列點選「**預設版面**」，將所有分析面板還原至預設排列位置。

## 面板說明

### 策略管理 (Equity Manage)

管理所有已載入的策略回測結果，每一列代表一個策略。

| 欄位 | 說明 |
|------|------|
| ✓ (啟用) | 勾選表示該策略納入合併計算；取消勾選則排除 |
| Index | 策略編號（自動產生） |
| 顏色 | 點擊可更改該策略在圖表中的顯示顏色 |
| Contract | 下單口數（乘數），數值愈大權重愈重 |
| Weight | 權重係數，預設為 1 |
| 名稱 | 可自訂的策略名稱 |
| 檔案名 | 回測結果檔案名稱（點「...」可更換檔案） |
| X | 刪除該策略 |

**其他功能：**
- **↑ / ↓**：調整策略排列順序
- **除以口數**：勾選後，圖表會將各策略損益除以口數，方便比較不同口數的策略
- **日期範圍**：可指定分析的起始與結束日期；勾選「全部」則使用全部資料範圍
- **固定獲利**：新增一條每期固定金額的虛擬損益曲線（用於比較無風險報酬）

### 績效摘要 (Summary)

以報表形式顯示整體投資組合的關鍵績效指標，詳細說明請參考 [報表項目說明](./report_items.md)。

報表分為四個區塊：
- **左側摘要**（期間、總獲利、MDD、獲利因子等）
- **右側摘要**（交易次數、勝率、Sharpe Ratio 等）
- **年度獲利** / **年度 MDD**
- **月度獲利** / **月度 MDD**
- **週獲利** / **週累積獲利**

---

### 損益曲線圖 (Plot)

繪製投資組合的累積損益走勢圖。

| 控制項 | 說明 |
|--------|------|
| 圖形類型 下拉選單 | 可選擇：總損益曲線、各策略曲線、總+各策略、回撤曲線 |
| 年份 下拉選單 | 選擇「全部」顯示整段時間；或選取特定年份只顯示該年 |
| 複製 / 儲存 | 可將圖表複製至剪貼簿，或儲存為 PNG 圖片 |

圖表上的**紅色水平線段**標示前 N 大 MDD（回撤）的起訖位置，N 由選項設定控制。

移動滑鼠可看到各日期的累積損益提示文字。

---

### 各期損益分析 (Period Bar)

以長條圖顯示各時間區段的損益或回撤。

| 控制項 | 說明 |
|--------|------|
| 圖形類型 下拉選單 | 可選擇：獲利、回撤、獲利+回撤、各策略獲利、各策略回撤 |
| 時間區間 下拉選單 | 全部（可選每年/半年/4月/3月/2月/月）；或指定特定年份 |
| 滾動平均 (Rolling) | 設定滾動平均期數，例如設 3 則顯示前 3 期平均值 |
| 複製 / 儲存 | 可將圖表複製至剪貼簿，或儲存為 PNG 圖片 |

---

### 各策略結果表 (Result Summary)

列出每個策略的獨立績效摘要，以及整體合計（ALL）。

| 欄位 | 說明 |
|------|------|
| Index | 策略編號 |
| 策略 | 策略名稱或檔案名 |
| 口數 | 下單口數 |
| Weight | 權重 |
| 獲利點 | 以點數計算的淨獲利 |
| 獲利 | 以金額計算的淨獲利 |
| 獲利(%) | 該策略獲利佔整體總獲利的比例 |
| MDD | 最大回撤金額 |
| 獲利/MDD | 淨獲利除以 MDD（PMR 指標） |

可點選「儲存報表」將結果匯出為 CSV 檔案。

詳細欄位說明請參考 [報表項目說明 - 勝負分析](./report_items.md#勝負分析)。

可點選「儲存報表」將結果匯出為 CSV 檔案。

### 部位最佳化 (Position Analysis)

針對多策略投資組合，測試不同口數組合下的績效表現。

**使用步驟：**
1. 點選「**Batch Run**」按鈕，設定各策略的口數搜尋範圍。
2. 確認後，系統自動計算所有口數組合的對應獲利與 MDD。
3. 結果列表顯示在表格中，欄位包含：獲利、MDD、獲利/MDD 及各策略口數。
4. **點選任一列**，可自動將對應口數套用到「策略管理」面板，立即更新所有圖表。
5. 點選「**輸出報表**」可用 VisualTable 開啟 CSV 格式的完整最佳化結果。

---

### 分潤試算 (Commission)

模擬基金管理/跟單平台的收入結構，以季為單位計算分潤、績效獎金、手續費退傭。

**設定入口：** 點選分潤面板中的「**設定**」按鈕可開啟設定對話框。

詳細設定項目請參考 [設定選項 - 分潤試算設定](./settings.md#分潤試算設定)。
