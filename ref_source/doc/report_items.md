# 報表項目說明

本文件說明 Visual Portfolio 各報表面板中每個欄位的意義與計算方式。

---

## 績效摘要 (Summary)

### 左側摘要欄

| 項目 | 說明 | 計算方式 |
|------|------|----------|
| **期間** | 策略執行總時長 | 以「年數」表示，計算第一筆至最後一筆交易之間的天數 / 365.25 |
| **總獲利** | 所有交易的累積淨損益 | Σ (每筆 netProfit × 口數 × 權重) |
| **年獲利** | 每年平均獲利 | 總獲利 / 年數 |
| **MDD** | 最大回撤（Maximum Drawdown） | 從任何高點到後續低點的最大跌幅金額（見下方詳細說明） |
| **總獲利/MDD** | 整體 PMR 指標 | 總獲利 ÷ MDD |
| **年獲利/MDD** | 年化 PMR 指標 | 年獲利 ÷ MDD |
| **贏錢總金額** | 所有獲利交易之損益加總 | Σ (netProfit > 0 的交易) |
| **輸錢總金額** | 所有虧損交易之損益加總 | Σ (netProfit ≤ 0 的交易)，為負數 |
| **獲利因子** | Profit Factor | 贏錢總金額 ÷ |輸錢總金額|；若無虧損則顯示 100 |
| **Sortino Ratio** | Sortino 比率 | √N × 平均每日超額報酬 ÷ 下行波動率（詳見下方） |
| **MDD 1 ~ N** | 前 N 大回撤 | 依回撤金額由大到小排列，顯示起始日期及持續天數 |

### 右側摘要欄

| 項目 | 說明 | 計算方式 |
|------|------|----------|
| **交易日期** | 交易時間範圍 | 第一筆至最後一筆交易的日期 |
| **交易次數** | 總完成交易筆數 | 計算所有 ClsTradeItem 的數量 |
| **贏錢次數** | 獲利交易筆數 | netProfit > 0 的筆數 |
| **輸錢次數** | 虧損交易筆數 | netProfit ≤ 0 的筆數 |
| **贏錢機率** | 勝率 | 贏錢次數 ÷ 總交易次數 × 100% |
| **平均每次輸贏** | 每筆平均損益 | 總獲利 ÷ 交易次數 |
| **平均每次贏錢** | 平均每筆獲利交易金額 | 贏錢總金額 ÷ 贏錢次數 |
| **平均每次輸錢** | 平均每筆虧損交易金額 | 輸錢總金額 ÷ 輸錢次數（負數） |
| **Sharpe Ratio** | 夏普比率 | √N × 平均每日超額報酬 ÷ 每日超額報酬標準差（詳見下方） |

### 年度/月度獲利表

| 項目 | 說明 |
|------|------|
| 年份 / 月份 | 對應的年度（YYYY）或月份（YYYY/MM） |
| 獲利 | 該期間的累積淨損益 |
| MDD | 該期間內的最大回撤 |

### 週度報表

| 項目 | 說明 |
|------|------|
| 週起始日 | 以週一為起點的日期（YYYY/MM/DD） |
| 當週獲利 | 該週的淨損益 |
| 累積獲利 | 至該週為止的累積淨損益 |

## 最大回撤（MDD）計算說明

MDD（Maximum Drawdown）透過「從高點到低點的最大損失金額」來衡量策略的最大連續虧損風險。

**計算方式：**
1. 依序累積每筆交易損益，追蹤目前累積損益的「歷史高點」。
2. 每次累積損益低於歷史高點時，計算差額（即「當前回撤」）。
3. 所有時間點中最大的回撤金額，即為 MDD。
4. 程式同時追蹤每次回撤的「起始時點」（高點）、「最低點時點」與「回復到高點的時點」，以便在摘要中顯示回撤詳情。

顯示格式：`$ 金額 (起始日期, 達到低點天數 - 完全回復天數 days)`

## Sharpe Ratio（夏普比率）計算說明

**計算步驟：**
1. 將所有交易按日期分組，計算每個交易日的當日損益。
2. 每日超額報酬 = 當日損益 / 資本金額（萬元）- 每日無風險利率
   - 每日無風險利率 = 年化無風險利率 / 每年交易日數 N
3. Sharpe Ratio = √N × 平均每日超額報酬 / 每日超額報酬標準差

> 無風險利率請至選項（Options）設定，預設為 3%（年化）。
> 資本金額請至選項（Options）設定，預設為 100 萬。

---

## Sortino Ratio（索提諾比率）計算說明

與 Sharpe Ratio 類似，但分母只考慮**下行（虧損）**的波動，忽略上行（獲利）的波動。

**計算步驟：**
1. 同 Sharpe Ratio 計算每日超額報酬。
2. 只取超額報酬為負值的部分（下行報酬）。
3. Sortino Ratio = √N × 平均每日超額報酬 / 下行標準差
   - 下行標準差 = √( Σ(負值超額報酬²) / 負值筆數 )

## 各策略結果表 (Result Summary)

| 欄位 | 說明 |
|------|------|
| Index | 策略編號；ALL 列表示整體合計 |
| 策略 | 策略名稱或檔案名 |
| 口數 | 下單口數（Contract） |
| Weight | 策略權重係數 |
| 獲利點 | 淨獲利以「點數」為單位。計算方式：NetProfit ÷ PointValue |
| 獲利 | 淨獲利（金額），含口數與權重計算 |
| 獲利(%) | 該策略獲利佔整體總獲利比例 |
| MDD | 該策略在指定日期範圍內的最大回撤（含口數與權重） |
| 獲利/MDD (PMR) | 淨獲利（點數）÷ MDD（點數）；ALL 列使用整體合計獲利 ÷ 整體 MDD |
| PointValue | 每點金額（由回測結果檔案讀入） |

## 勝負分析 (Win/Loss)

以日（每筆交易）、週、月、年四個維度統計勝率與贏輸金額。

| 欄位 | 說明 | 計算方式 |
|------|------|----------|
| 總次數 | 各時間維度的期數總計 | 計算日/週/月/年的群組數量 |
| 贏錢次數 | 該維度中結果為正的期數 | |
| 輸錢次數 | 該維度中結果為負或零的期數 | |
| 贏錢機率 | 贏錢次數 / 總次數 | 以百分比顯示 |
| 平均每次贏錢 | 獲利期的平均獲利金額 | Σ正值 / 贏錢次數 |
| 平均每次輸錢 | 虧損期的平均虧損金額 | Σ負值 / 輸錢次數 |
| 最大贏錢 | 獲利最多的一期金額 | |
| 最大輸錢 | 虧損最多的一期金額 | |
| 每次贏輸比 | 平均每次贏錢 / |平均每次輸錢| | 衡量每次獲利與虧損的比值 |
| 全部贏輸比 | 贏錢總金額 / |輸錢總金額| | 衡量總體獲利與虧損的比值 |

## 部位最佳化 (Position Analysis)

透過 Batch Run 窮舉各策略的口數組合，計算每種組合的績效。

| 欄位 | 說明 |
|------|------|
| Index | 排列組合的編號 |
| 獲利 | 該口數組合的總獲利金額 |
| MDD | 該口數組合的最大回撤金額 |
| 獲利/MDD | 獲利 ÷ MDD（PMR 指標） |
| 各策略名稱欄 | 該組合下各策略使用的口數 |

## 分潤試算 (Commission)

以季為單位計算各類收入，適用於基金管理或跟單平台的收益試算。

### 每季項目

| 欄位 | 說明 |
|------|------|
| 季別 | 第一季 ～ 第四季，以及全年合計 |
| 季初資金 | 該季期初的可用資金（初始資金隨策略績效動態更新） |
| 季末資金 | 該季期末的資金 |
| 獲利 | 季末資金 − 季初資金 |
| 季績效 | 獲利 ÷ 季初資金 |
| 分潤 | 若累積獲利為正，按「季分潤 %」抽成；抽成後清零 |
| 客戶淨獲利 | 獲利 − 分潤 |
| 手續費退傭 | 依總成交金額、幣安手續費率及退傭率計算 |

### 每年項目

| 欄位 | 說明 |
|------|------|
| 年度績效 | 全年客戶淨獲利 ÷ 年初資金 |
| 獎金級距 | 根據設定的績效門檻比對年度績效，對應的獎金比例 |
| 績效獎金 | 全年客戶淨獲利 × 獎金級距 |
| 全年手續費退傭 | 全年各季手續費退傭合計 |
| 全年分潤 | 全年各季分潤合計 |
| 綜合收入 | 績效獎金 + 手續費退傭 + 分潤 |
